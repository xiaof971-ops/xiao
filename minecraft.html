🎮 说明：本页是开源项目 Eaglercraft（把 MC Java 版编译到浏览器运行的粉丝作品）的中文整合版入口，与 Mojang / Microsoft 无关，仅供学习体验。 游戏资源由 mcjs.link 及其镜像提供，世界存档保存在你自己浏览器的本地存储里，清除浏览器数据会丢档，重要存档请在游戏内导出备份。 推荐 1.8.8 WASM 版：体积最小、支持光影；老电脑或触屏设备若 WASM 版异常，换 1.8.8 JavaScript 版兼容性最好。 个别远古版本（Alpha / Beta 等）暂无法在本页内嵌，点卡片上的按钮会带你到官方门户选线路进入。
