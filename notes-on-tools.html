工具 2026-11-17

我的效率工具清单（2026 版）

工欲善其事。这篇整理我日常真正高频使用的工具——不是"装过"，而是每天都会打开的那种。判断标准只有一条：它是否实实在在替我省了时间或心神。

写与记

  • 腾讯文档 / Notion。所有第一稿都写在云文档里：随手打开、多端同步、再也不用操心"存在哪台电脑上"。个人长期资料放 Notion，需要分享协作的放腾讯文档。
  • flomo。灵感捕捉器。想到什么两秒记一条，不分类、不纠结格式——反正后面会整理。它解决的不是"记"，是"别让念头溜走"。
  • Obsidian。深度笔记的家。双向链接 + 本地 Markdown，笔记永远是我自己的文件，不怕哪家服务关门。
  • WorkBuddy / Claude。从润色到扩写再到"帮我把这段口语变成书面语"，现在是写作流程的固定一环。省下的不是打字时间，是组织语言的心理成本。

开发

  • VS Code + GitHub Copilot。2026 年这已经不是"要不要用"的问题，而是"怎么用得好"。我的经验：把需求和约束说清楚，比让 AI 自由发挥重要得多。
  • 终端 + Git。没有花哨的替代品。会用命令行的人，迁移到任何环境都不慌。
  • WorkBuddy。现在最重的生产力工具：写文档、做 PPT、分析表格、搭小程序都能一句话扔给它。我的博客小游戏就是和它协作半天写出来的。AI Agent 类工具的关键不是"能干活"，是"敢把整件事交给它"。
  • Postman。调接口的老朋友。麻烦不麻烦，试一下就知道。

日常提速

  • uTools / Raycast。快捷启动器，一个快捷键唤起一切：剪贴板历史、二维码、翻译、取色。装好之后鼠标使用率肉眼可见地下降。
  • Everything（Windows）。秒搜全盘文件，装完就回不去系统自带的搜索了。
  • Snipaste。截图 + 贴图。把截图钉在屏幕上对着抄参数、对着写代码，谁用谁知道。
  • 滴答清单。脑子只负责想，清单负责记。打勾那一下的爽感，是坚持的动力。

知识管理

我的原则很克制：工具越少越好，一条链路走到底。见过太多人把时间花在折腾笔记软件上，而不是记笔记本身。现在的链路是：flomo 随手记 → 每周日整理进 Obsidian → 值得发布的搬上这个博客。

工具的目的是让你忘记工具。如果一个工具总需要你维护它，它就从助手变成了负担。

踩过的坑

  • 追新。每年都有"颠覆性"的新工具，绝大多数活不过两年。现在我只换工具，不追工具。
  • 过度自动化。自动化的维护成本经常超过它省下的时间。只有每周都用得到的流程，才值得自动化。
  • 收集癖。收藏夹不是知识库。看过、用过、写下来的，才属于你。
